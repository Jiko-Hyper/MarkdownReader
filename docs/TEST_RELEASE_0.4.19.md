## 2026-10-15：默认打开器与长公式文档交互

实际电脑的 `.md` UserChoice 已选择 Applications/MDReader.exe，但打开命令仍指向已不存在的 0.4.12 目录。登记当前安装目录的正确入口，应用名称统一为 MDReader；补齐 RegisteredApplications、Capabilities 与 .md FileAssociations，保留用户默认选择及其他阅读器。每次安装和升级更新关联路径。安装窗口新增默认打开器复选框，软件「更多」增加设置入口，选择后进入 Windows 默认应用设置确认。卸载只移除仍指向本安装的登记。

使用实际阅读的 114,149 字节文档，在隔离工作区测出 505 个公式、14 张表格。安装版与源码测试版的相关源码、Python/Tk 版本及 Tk DLL 指纹相同；同一文档在源码测试入口也复现，说明无法归因于安装版运行库。原实现每次缩放在 UI 线程同步重画整篇公式：安装版首次 5,236.684 ms，缓存命中后 651–679 ms；源码首次 4,174.195 ms，后续 706–875 ms。普通翻页自身约 3–52 ms，缩放占用 UI 线程时会阻塞后续翻页和滚动。

改为优先刷新可见公式，后台单工作线程生成 PNG，UI 定时器分批替换图片，复用有上限的已解码图片缓存。快速连续缩放只应用最新目标字号，切换文档取消旧刷新队列；小文档保留即时更新。复用公式渲染器既有 GDI 锁，缓存读写也串行保护，每个写入线程使用独立临时文件，避免 Windows 读写共享冲突。工作线程不调用任何 Tk 方法。修正未落盘公式缓存的缩放回退，以及重复缩放定时器。

源码随包运行环境对同文档复验，缩放同步响应为 41.732–145.081 ms，整篇公式约 4.5–6.2 秒在后台逐步完成；这不是声称整篇重画时间缩短到几十毫秒。保留原文、标签和公式，模型不重打包。覆盖大量公式异步刷新、最新字号、重复公式图片复用、切换文档取消、内存缓存回退、慢公式期间 UI 计时器和翻页继续工作、并发缓存写入，以及已有公式、IME、多标签、安装和包布局检查。基准记录在工作区 output/reader-performance-*.json。
