# MDReader

把一个普通文件夹里的 `.md` 文件，变成**排版好看、能直接读**的电子文档；
顺便把散落各处的 Markdown 收进「项目」里统一管理。

Windows 桌面工具 · 纯本地运行 · 不需要联网 · 不上传任何文件。

## 怎么开始（免安装版）

从 Releases 下载 `MarkdownReader-<版本>-win64.zip`，解压后：

1. 双击 **`MDReader.exe`**（包里自带 Python 运行时，目标机器不用装任何东西）；
2. 点「打开本地文件」或按 Ctrl+O 选择 `.md` 文件；也可以直接拖入文件或文件夹，不必先建项目；
3. 阅读后可查找、切到源码修改，再点工具栏「导出 Word/PDF」选择交付格式。

桌面导出入口始终可见。对应插件未安装时可点「安装并启用」，只安装所选格式的随包插件；已安装但停用时可直接启用。无需配置 AI，也不需要联网。缺少随包文件或校验失败时会说明原因，并提供「插件管理」入口选择官方本地包。安装启用后，再次选择文档并点击导出。

导出完成窗口显示本次文档、实际保存位置及降级提示，提供「打开文件」「打开所在文件夹」。即使切换了文档，这两个按钮仍指向刚才生成的文件。

想留一个桌面图标：右键 `安装到桌面.ps1` → 「使用 PowerShell 运行」。
完整卸载：运行 `卸载.cmd`，核对安装时选择的程序与数据两个目录，输入 `DELETE`，删除两处全部内容。请先备份。

从源码运行的命令见根目录 `README.md`。

## 插件（0.2.8 起内置机制，插件包另行发布）

从这一版开始，**图片插入**与 **PDF / Word 导出**改由**可选插件**提供。核心功能
（打开文件夹、读写与删除保护、撤销、表格、主题、图片与公式阅读、HTML 导出）
**不需要任何插件**，一个插件都不装也能正常用。

怎么用：

- 桌面窗口点「⋯ 更多 → 插件管理…」，或在网页侧栏点「🧩 插件管理」；
- 点「安装本地插件包…」，选择维护者发布的插件包（`.zip`）；
- 在通用插件管理中安装后默认**不启用**，需要你自己点「启用」；工具栏导出引导的「安装并启用」会在明确点击后完成这两步。禁用、卸载仍在插件管理中；
- 启用后，「⋯ 更多」菜单里会出现该插件的命令（例如「插入图片」或「用插件导出」）；
  禁用后入口立刻消失，服务端也会直接拒绝调用。

几条明确的边界（安装前请先读）：

- **只接受维护者发布、并在程序自带的受信清单里登记过 SHA256 的插件包**。清单里
  没有的 id、或包内容与登记的哈希不一致，安装会被拒绝并说明原因。界面**没有**
  “忽略来源检查”的开关。三个正式插件（图片插入、PDF 导出、Word 导出）已经发布为
  **`1.0.2`**，哈希登记在随程序分发的受信清单里；升级到新版本走的是同一条安装入口。
- 插件代码在**独立进程**里执行，产物路径、文件类型与大小都会由程序重新校验，
  工作目录之外的文件一律拒绝；插入的图片、正文提交和导出文件的最终写入仍由
  核心完成（覆盖确认、修订校验、撤销都照旧生效）。
- 独立进程**不是安全沙箱**：受信插件仍有你当前用户的系统权限。本程序不面向
  运行来源不明的第三方脚本。
- **卸载只删除插件代码和它自己的缓存**，绝不删除你的 Markdown、已插入的图片或
  已经导出的文件。
- 插件任务在等待时可以取消；禁用插件会立刻取消它正在跑的任务，被取消的结果
  不会写进文档。窗口关闭时正在跑的插件任务会被结束。

## 检查当前文档的链接

写完一篇带图片和跳转的笔记后，可以点 **桌面「⋯ 更多 → 检查当前文档链接…」** 或 **网页顶栏「🔗 检查链接」**，它会检查**当前这一篇**：

- 图片或文档链接指向的文件**找不到**；
- 引用**越出了文档所在目录**（例如 `../别处/图.png`）；
- 写的是**绝对路径**（`C:\…`），换台电脑就失效；
- 跳转的标题（`#小节`）在本文档里**不存在**；
- 「文档链接」指向的不是 Markdown 文件。

每条都带**行号**：

- 「定位到源码」会切到源码并选中那一行；
- 图片找不到时，桌面端还可以「**重新选择文件…**」：选中的文件会**复制**到文档旁边的
  `assets/`（同名自动加序号，不覆盖已有文件），正文里的引用改成相对路径；
  改动只在编辑缓冲区里，**要按保存才会写回文件**，而且一次替换可以一次撤销。

几条边界：只检查**当前这篇文档**（不会扫描整个文件夹，也不会改别的文档）；外部网址不检查、
也不抓取；代码块与行内代码里的 `$`/链接写法不会被当成引用。网页端目前只提供「定位」，
「重新选择文件」在桌面端。

## 导出：先检查，再确认（从 0.2.8 起）

用插件导出 PDF / Word 时，程序会先替你看一遍这篇文档：

- **有未保存的修改时**先问一句：导出「**当前编辑内容**」（推荐）还是「**磁盘已保存版本**」。
  导出**不会**替你保存源文件；选好之后导出的就是那一刻的固定内容，之后再改也不影响这一份。
- **导出前检查**会列出两类东西：
  - **必须先处理**（会阻止导出）：图片找不到、图片不在已授权目录里、文档是空的；
  - **可以继续的提示**（确认后按提示导出）：暂时画不出来的公式（导出稿里保留原始写法）、
    超过 12 列的宽表、指向不存在文件的本地链接、本机缺少导出用的字体、文档特别大。
  点「返回修改」就什么都不会写；点「仍然导出」才会真的生成文件。
- 目标文件**已存在**时会先让你确认；如果确认之后它又被别的程序改过，会再问一次，
  不会覆盖你没看过的新版本。导出目标也**不能**是源文档自己。
- 导出过程在目标文件夹里先写临时文件，成功后才替换；失败或取消**保留原目标**。
- 桌面导出时，窗口中央会显示与当前主题一致的进度弹窗。点击 **取消导出**、按 Esc 或关闭该弹窗可取消尚未提交的导出；成功提示出现后表示文件已经保存。
- 打印版式固定为 **A4、浅色**，与阅读主题（明亮/夜间/护眼）无关。

## 数学公式（离线渲染）

在桌面或网页的源码工具栏点「∑ 公式 ▾」，选择「行内公式」或「独立公式」。
选中现有表达式再点按钮，会把它变成公式；没有选区时会插入 `$x$` 或分数模板，
表达式已选中，可直接打字替换。行内公式也可按 `Ctrl+Shift+M` 插入。
切到预览即可看到排版；保存仍需按 `Ctrl+S`。也可以直接手写下面的 Markdown 语法。

正文里用 `$…$` 写行内公式、用单独一行的 `$$…$$` 写独立公式，阅读时会**在本机画成图片**显示，不需要联网、不需要额外插件：

```text
质能关系 $E = mc^{2}$，温度系数 $23 \times 10^{-6}/K$。

$$
\frac{\partial u}{\partial t} = \kappa \nabla^{2} u
$$
```

- 支持的范围（固定样本，不是完整 LaTeX）：分数 `\frac{}{}`、上下标 `^{}`/`_{}`、根号 `\sqrt{}`/`\sqrt[3]{}`、希腊字母、求和 `\sum`、连乘 `\prod`、积分 `\int`/`\oint`（带上下限）、极限 `\lim`、`\left(…\right)` 自适应括号、矩阵 `\begin{pmatrix}…\end{pmatrix}`、`\begin{bmatrix}`、分段 `\begin{cases}`、对齐 `\begin{aligned}`、组合数 `\binom{}{}`、重音 `\vec \hat \bar`、中文 `\text{…}`、黑板粗体 `\mathbb{R}`。
- 不认得的写法**不会被猜**：正文里保留你写的原始表达式，旁边给出原因（鼠标停在上面能看提示），其他内容照常显示与保存。
- `\$` 表示普通美元符号；`$5 与 $6 元` 这类金额文本不会被当成公式；行内公式不能跨行，内容首尾不能是空白；代码块与行内代码里的 `$` 不参与。
- 公式图片按“表达式 + 字号 + 缩放 + 主题”缓存在工作区的 `formula-cache/` 里，缩放与换主题时会按新参数重画；**导出的 HTML 会把公式图片内嵌进去**，断网打开也能看。
- 已知限制：排版细节不如 KaTeX（没有可变长括号、间距是经验值）；导出 **PDF / Word 时公式会嵌成图片**（Word 里不可编辑、PDF 里不可检索，原始写法写进图片的替代文字，导出时会明确提示）——**没有**实现可编辑的 Office 公式。

## 插入图片（三种方式）

插入图片需要先安装并启用**图片插入插件**（见上面「插件」一节）。插件就绪后，桌面窗口与网页端都可以用下面三种方式，效果一样：附件保存到文档旁边的 `assets/` 目录（自动取唯一文件名），正文里写入标准的

```text
![说明](assets/图片名.png "width=720")
```

- **选择文件**：桌面「⋯ 更多 → 插入图片（图片插入）…」，网页「🖼 插入图片」。中文名、空格、括号路径都可以。
- **粘贴截图**：桌面按 `Ctrl + Shift + V`（或「⋯ 更多 → 粘贴剪贴板图片（截图）…」）；网页在源码编辑器里直接 `Ctrl + V`。截图先在本机落成临时文件，插入完立刻删掉；**你在资源管理器里「复制」的那张图片是原件，程序只读不删**。剪贴板里没有图片时会提示，不会改动正文。
- **拖进窗口**：把图片文件（或从网页拖一张图）拖到窗口里，就插到当前文档的光标处——按 `Shift` 拖进来仍然是原来的导入规则。一次拖入多张只插第一张，并会告诉你其余几张没有处理；同一次拖放里的 `.md` 仍然按原样**临时打开**。

几条要知道的：

- 桌面端每次插入会先问你图片宽度（默认 720 px，只影响显示宽度，**原图不会被压缩或改写**）。
- 图片宽度需在 **16–4096 像素**之间，太小的图会被插件拒绝并说明原因。
- 一次插入对应**一次撤销**（`Ctrl + Z` 一次撤掉刚插入的那一行）。
- 插入不改动你的源文件——正文改动留在编辑器里，按 `Ctrl + S` 才写回。

## 表格与常用格式工具栏（源码模式）

按 `Ctrl+E` 切到源码模式后，工具栏下面多了一排编辑按钮：

- **▦ 插入表格…**：填列数、数据行数，勾选「首行作表头」，逐列选左对齐 / 居中 /
  右对齐，确定后就在光标所在行之后插入一张标准 Markdown 管道表格（前后会自动
  留空行）。快捷键 `Ctrl+Shift+T`。
- **编辑当前表格…**（在「⋯ 更多」里，或把光标放在表格里点工具栏）：改单元格、
  增删行列、改表头与对齐。**只在看得懂的结构上动手**——列数对不上、各行竖线写法
  不一致、表格在代码块里，都会保留源码并告诉你原因，不会猜着重写。
- **H 标题 ▾ / B 粗体 / I 斜体 / • 列表 / 1. 有序 / ❝ 引用 / </> 代码 / 🔗 链接**：
  选中文字就套在选区上，再点一次取消；没选文字就插入一对空标记或模板，光标停在
  中间。一次操作对应**一次撤销**（`Ctrl+Z` 一次回到操作前）。
- **粘贴表格**：从 Excel、网页表格或其它编辑器复制多行多列的文本后，在源码里
  `Ctrl+V`，程序会先给一张「几列几行」的预览，并列出不能原样处理的地方（含引号、
  某行列数不一致等），确认后才写入。**普通文字粘贴不受影响**。
- 单元格只支持单行文本：内容里的 `|` 和 `\` 会自动转义，换行会被明确拒绝（不会
  为了“能插进去”把换行写进 Markdown）。列数上限 24、行数上限 400；超过 60 行或
  16 列的表格不进弹层，直接改源码更快。
- 阅读时列很多的宽表会**在窗口宽度内换行显示**（不撑破窗口、不丢列）；导出 PDF /
  Word 时同样不会裁掉最后几列。

## AI 选区修改（下一个维护更新，开发中）

只想改一段、不想让 AI 重写整篇时用它：

1. 在源码模式下**选中要改的文字**（预览模式下也可以，程序会切到源码并保留选区）。
2. 打开「更多 → AI 接入…」，在「选区修改」一排里点一种改法：**润色 / 精简 / 扩写**，
   或者把要求写进下方输入框后点**自定义要求…**。
3. 看输出的「原文 → 建议」差异，再决定：
   - **应用建议**：只替换你选中的范围，范围外一字不动；`Ctrl+Z` 一次撤销；按 `Ctrl+S` 才写回文件。
   - **取消建议**：正文没有任何改动。

发送范围默认是**仅选区**。需要 AI 看到更多上下文时，在「发送范围」里改成
「选区所在段落」或「整篇文档」——程序会在发送提示里写出**实际字数和字符区间**，
先看清楚再决定。

不会发生的事：请求发出后如果切换了文档或改动了正文，这份旧建议会被**拒绝应用**
并提示重新生成；截断回复、格式错误、空白结果都不会变成可应用的正文；应用不会自动
保存。选区以外的正文也不会被悄悄发给服务商。

首版只有**桌面窗口**入口；网页端的 AI 助手仍是"附上整篇文档、返回整篇"的方式。

## 0.2.8 切换视图和文档后仍可继续撤销

以前在「预览」和「源码」之间来回切换，或者切到另一份文档再切回来，`Ctrl+Z` 就只能撤销到切换之后的位置——刚才的编辑撤不回来了。现在每份打开的文档都保留自己的编辑区和撤销历史：

- **预览 ↔ 源码**来回切换，撤销、重做、光标位置和选中的文字都不受影响；
- **切换标签**只切换显示，A、B 两份文档各自的内容、撤销历史和光标互不干扰；
- 保存后继续输入再撤销：回到上次保存的内容时「未保存」标记消失，重做离开基线时标记又会出现；
- 关闭标签会释放对应的编辑区和输入法适配项，打开二十份文档再逐一关闭后不会有残留。

更新后正常关闭旧窗口，再从桌面快捷方式启动，标题应显示 **MDReader 0.2.8**。

## 0.2.7 阅读更保真，网页与桌面更像同一套

Markdown 排版做了两套引擎的逐项对比：内置引擎补上了缩进代码块，图片/链接的标题不再丢失，列表里「空行 + 缩进段落」不再被误当成代码。脚注、公式、Mermaid 这类暂不支持的内容会原样显示文字，不会消失。

网页和桌面窗口现在共用同一组配色：三种主题的底色、正文色、次要文字色、描边和悬停色完全一致，在任意一边换主题另一边都会跟着换；护眼主题的次要文字加深了一点，读起来更清楚。

更新后正常关闭旧窗口，再从桌面快捷方式启动，标题应显示 **MDReader 0.2.7**。

## 0.2.6 导出与导入更谨慎

导出 HTML 时，如果目标文件已经存在，会让你确认后再覆盖（默认位置会另存一个新名字，不会顶掉上一次的导出）。从浏览器界面导出时也不再因为缺少会话凭据而失败。

导入始终是复制，同名文档会自动改名而不是覆盖；只有你明确选择「移动」才会移动原文件。导入文件夹会连同里面的图片一起带过来。

## 0.2.5 保存更安全，查找和主题两端一致

保存前会核对磁盘内容：如果文件被别的程序改过，普通保存会被阻止，你可以看差异、另存为，或选择「备份后覆盖」（覆盖前会先把磁盘版本备份到工作区的 `.recovery\conflicts`）。原来的编码和换行方式会保留；文件被移走或删除时，缓冲区内容不会丢。

编辑过程中会自动写恢复快照（停下约 2 秒、持续输入至少每 15 秒一次）。异常结束程序后重新打开，会提示是否恢复。

网页界面补上了 **🔍 查找（Ctrl+F）** 和 **📑 目录（Ctrl+L）**，并会记住每份文档的阅读位置；主题也和桌面窗口共用了：在网页里换主题，桌面窗口会跟着换，反之亦然。

## 0.2.4 输入法候选框与「更多」菜单

打字时拼音下方的系统候选词栏不再压在拼音上：程序会把组合文字的真实位置告诉 Windows 输入法，候选词栏固定排在拼音下面一行。侧栏「最近打开」的**搜索框**也使用同样的内嵌拼音，不再弹白框。

工具栏「浏览器视图」右边新增 **⋯ 更多**，目前包含「关于 MDReader」「打开工作区文件夹」「快捷键说明」；浏览器视图窗口的工具栏也有同一个入口，后续新增的次要功能会放在这里。候选词栏本身的颜色和字体仍由你的系统输入法决定，程序不会修改系统输入法设置。

## 0.2.3 输入外观

夜间和护眼模式下，正在输入的拼音组合文字与正文使用相同背景、字体和字号，以细下划线提示组合状态，不再使用突兀的白底组合框。下方候选词栏仍是系统输入法的原有样式，不会修改你的系统输入法设置。此优化用于 Windows 内置编辑区，不同输入法的兼容效果可能有所不同。

## 新建标签与保存

点击顶部标签栏的 **＋**（或按 Ctrl+N）即可新建 `#Untitled`，直接编写 Markdown。按 **Ctrl+S** 选择位置并保存为 `.md` 后，标签前的 `#` 消失；再次编辑会重新显示。可以连续新建多份文档，彼此独立。

未保存时关闭标签或退出软件，窗口中央会出现 **是 / 否 / 取消**：带颜色的“是”保存，“否”放弃，“取消”继续编辑。如果取消文件保存窗口或保存失败，文档不会关闭。

上述标签功能用于内置 Windows 窗口。

## 阅读主题

将鼠标放到工具栏“主题”按钮上，或点击它，下拉选择“明亮 / 夜间 / 护眼”。选择后菜单收起，也可以点击其他位置或按 Esc 收起。夜间采用深灰阅读背景与柔和浅色文字，侧栏、输入框、滚动条和按钮统一配色；护眼采用暖米色正文背景、灰绿色侧栏和深绿色文字。护眼是阅读配色选项，不改变显示器亮度。

桌面窗口的主题会保存在工作区 `ui-settings.json`，下次打开自动恢复。浏览器视图同样提供三种主题并记住选择。切换主题保留源码编辑、未保存状态和阅读位置。

## 0.2.0 桌面窗口更新

顶部文档标签支持同时打开多份文件，点击 × 或按 Ctrl+W 关闭当前文档，Ctrl+Tab 切换，Ctrl+O 多选打开。同一路径重复打开会定位已有标签。每个标签保留阅读位置、源码模式和未保存内容，关闭或退出前会提示保存。

“最近打开”可搜索文件名和路径，按 Esc 清除搜索。选中一条记录后点击“删除选中记录”、按 Delete，或右键选择“删除打开记录”，都只移除历史，保留原文件和已打开的标签。

此版本启用 Windows 高 DPI 显示，修复正文列表换行并改进表格排版。上述标签页功能用于内置 Windows 窗口。

## 一、最快上手

### 只想赶紧看一眼某个 .md —— 拖进来就行

把 `.md` 文件**拖进窗口**，或者**拖到桌面图标上**，立刻就是排版好的正文。
这类文件属于「**临时查看**」：

- 不复制、不导入，软件只记住它的路径；
- 切到 **✎ 源码** 改完，`Ctrl + S` **直接写回原来那个文件**；
- 左侧「最近打开」保留记录，双击可切换，右键可以移出列表（**不会删文件**）；
- 想长期管理，点正文上方的 **＋ 加入项目** 复制进项目（也可以选移动）。

新写的临时文档没有落盘，第一次保存时会弹出「另存为」让你挑位置。

### 想建个资料库 —— 用项目

1. 双击桌面上的 **MDReader** 图标（或 `启动 MDReader.bat`）。
2. 点 **＋ 新建项目** 建一个项目文件夹。
3. 点 **⬆ 导入文件 / 导入文件夹**，或把文件夹、多个文件拖进窗口。

> 拖放的区分：**拖文件** = 临时查看原文件；**拖文件夹** = 导入成项目文档；
> 按住 **Shift** 拖文件 = 也导入成项目文档。

左侧是文档树，右侧就是排版好的正文。想改内容就切到 **✎ 源码**，`Ctrl + S` 保存。

## 二、三个核心功能

### 0. 临时查看：打开就能改，改的就是原文件

面向「手边有个 .md，想马上看、顺手改两句」的场景，不产生任何副本：

| 入口 | 行为 |
| --- | --- |
| 把 `.md` 拖进窗口 | 临时查看 |
| 把 `.md` 拖到桌面图标 / `启动 MDReader.bat` 上 | 临时查看 |
| 侧栏 **📂 打开本地文件**（可多选） | 临时查看 |
| 侧栏 **＋ 新建临时文档** | 新建，首次保存时选位置 |
| 正文上方 **💾 保存回原文件** | 写回原路径 |
| 正文上方 **另存为…** | 换个位置保存，并继续跟踪新文件 |
| 正文上方 **＋ 加入项目** | 复制/移动到项目里，变成受管理文档 |

文件不在原位置了、「最近打开」里会标 ⚠，点它会提示你，不会静默失败。
单文件超过 8 MB 会拒绝打开，避免把窗口卡死。

### 1. 把机器可读的 Markdown 变成人能读的排版

| Markdown | 读起来的样子 |
| --- | --- |
| `# 标题` `## 子标题` | 分级标题、自动缩进与分隔线 |
| 表格 `\| a \| b \|` | 真正的表格（可横向滚动） |
| ` ```python ` 代码块 | 代码面板 + 语言标签 + 一键复制 |
| `> 引用` | 带左侧色条的引用块 |
| `- [ ] 待办` | 可勾选的复选框 |
| `**粗体**` `*斜体*` `~~删除` | 正常排版 |
| `==高亮==` | 黄底高亮 |
| `![图](assets/x.png)` | 图片直接显示 |
| 文档顶部的 `---` front matter | 抽出来做成顶部标签，不在正文里碍眼 |

另外还会显示 **行数 / 字符数 / 标题数 / 更新时间**，正文底部有上一篇、下一篇的跳转。
内置 **深色 / 浅色主题**，阅读宽度可切换（`☰` 折叠侧栏）。

### 2. 用「项目」管理文件夹

- **项目 = 磁盘上一个真实文件夹**，位置在 `%USERPROFILE%\MDReader\projects\`。
  文件夹里就是普通的 `.md` 文件，用记事本、VS Code、Git 一样能改，不锁格式。
- 项目内可以**建子目录**（新建文档时填「放入子目录」），左侧按目录树展示。
- **导入**：单个/多个 `.md`，或整个文件夹（保留原来的目录结构）。
- **重命名、移动、删除**（删除默认进 Windows 回收站，可还原）。
- **搜索**：左侧搜索框输入关键词，全项目正文 + 文件名一起搜，回车即出结果。
- **打开目录**：一键在资源管理器里定位项目文件夹。
- **导出**：
  - 单篇 → 一个**离线单文件 HTML**（图片内嵌成 base64，发给谁都能看）
  - 整个项目 → **一本书式的合集 HTML**（带目录）
  - 导出页上带「切换主题 / 打印·存 PDF」按钮

项目文件夹结构：

```
%USERPROFILE%\MDReader\
├─ workspace.json
├─ projects\
│  └─ 我的笔记\
│     ├─ project.json        ← 项目名称等元信息（可删，不影响阅读）
│     ├─ docs\               ← 你的 .md 都在这里
│     │  ├─ 首页.md
│     │  └─ 设计\接口.md
│     └─ assets\             ← 图片放这里，用 ../assets/xx.png 引用
└─ exports\                  ← 导出的 HTML 默认落在这里
```

## 五、界面是怎么显示的（重要）

程序自带两层界面，会自动选一个：

1. **内嵌浏览器视图**（最接近网页排版）：需要系统里有 `WebView2Loader.dll`。
   大多数开发机装了 WebView2 SDK 的就有；没有的话不要紧，自动用第 2 种。
2. **内置原生窗口**：纯 tkinter 实现，自带 Markdown 排版（标题、列表、表格、
   代码块、引用、复选框……），**不依赖任何额外组件，一定能开**。
   右上角有一个 **浏览器视图** 按钮，可以在 Edge / Chrome 里打开同一份界面
   （网页版的代码高亮和表格滚动更漂亮）。

两种窗口功能一致，数据也完全一致。

> 内嵌浏览器依赖匹配架构的 WebView2 Runtime 与官方 SDK 提供的加载器。
> 请只使用可信官方组件；组件不可用时使用原生窗口或浏览器模式。

## 六、目录结构与安装

```
MDReader\                      ← 装在这里（默认 %LOCALAPPDATA%\MDReader）
├─ main.py                     ← 程序入口
├─ 启动 MDReader.bat            ← 双击启动（也可把 .md 文件拖到它上面）
├─ mdreader\
│  ├─ core.py                  ← 工作区模型 + 本地 HTTP 接口 + 临时查看
│  ├─ storage.py               ← 原子写入、路径边界
│  ├─ render.py                ← Markdown → HTML 排版引擎
│  ├─ launcher.py              ← 窗口与启动逻辑
│  └─ winui.py                 ← 内置原生窗口（含系统拖放）
├─ webui\                      ← 界面（index.html / app.js / app.css）
├─ 安装到桌面.ps1               ← 再次创建桌面快捷方式
└─ 卸载.ps1                     ← 完整删除记录中的程序与数据目录
```

- **运行环境**：本机已安装的 Python 3.9+（当前机器是 3.12）。
- 程序只监听 `127.0.0.1` 本机回环地址，防火墙对外不可见。
- 完整卸载删除安装时记录的程序和数据两个目录，**数据目录中的文档与设置也会删除，请先备份**。
  临时查看打开的文件本来就在你自己的目录里，程序从不复制或移动它们。

### 高级启动参数

```
python main.py                 正常启动
python main.py --browser       只用系统浏览器（不开窗口）
python main.py --workspace D:\笔记   换一个工作区目录
python main.py --port 8642     固定端口
python main.py --open 文件.md   以临时查看方式打开某个文件（可多个）
python main.py --selftest      自检窗口能不能起来
```

## 八、已知限制（请先读这一节）

**运行环境**

- Windows Release 包自带 Python 运行时，完整解压后运行 `MDReader.exe`，无需另装 Python。从源码运行才需要 Python 3.9+（含 tkinter）。
- 内嵌浏览器视图需要系统里有 `WebView2Loader.dll`；没有时自动使用内置 tkinter 窗口，功能一致但排版略有差别。
- 本版本只在 Windows + Python 3.12 上完整验证；其他 Python 版本未做兼容性承诺。

**Markdown 支持**

- 数学公式支持上文列出的 TeX 子集；不支持的命令保留源码与提示。脚注和 Mermaid 图表暂不提供跳转或图形渲染。
- 原始 HTML 出于安全考虑不执行（会按文本显示）；`==高亮==`、`[[wiki 链接]]`、任务列表复选框是本程序的扩展。
- 内置回退引擎（没有 `markdown-it-py` 时使用）与主引擎在共同支持的语法上一致，但不等于完整 CommonMark；复杂文档建议安装 `markdown-it-py`。

**保存与恢复**

- 覆盖保护基于内容指纹：不配合文件锁的外部程序（共享目录、云同步目录）在"检测"和"写入"之间仍可能存在竞态，这类环境需要单独验证。
- 恢复快照是尽力而为：默认停止输入约 2 秒后写入、持续输入期间至少每 15 秒一次，不等于零丢失；快照有单条 32 MB、500 条、总量 256 MB 的上限。
- 中文输入法的候选词栏外观与具体行为由系统输入法决定，程序不修改输入法设置；不同输入法的实测效果可能不同。

**其它**

- **插件**：插件机制已内置，四个正式插件：图片插入 1.0.2、Word/PDF 导出 1.0.4、文档格式转换 1.0.0，安装包在仓库的 `plugins/packages/`，受信哈希登记在
  随程序分发的 `plugin_trust.json` 里；仓库里的 `plugins/samples/*` 只是验证机制用的样例
  （导出扩展名 `.samplea` / `.sampleb`，不是真正的 PDF 或 Word）。独立进程不是安全沙箱；
  网页端上传的插件包与图片受 24 MB 请求上限约束；插件任务没有跨重启的队列。
- **导出里的特殊符号**：数学减号（−）与上下标（⁻ ⁶ ₁ ₂ ²）在中文字体里没有字形，PDF / Word 导出会
  自动换用带这些字形的西文字体，中文正文不变；只有在所有可用字体都没有该字形时才留空，并在结果里
  提示受影响的字符。以前这一条会让这些符号在导出稿上变成空白（0.2.8 的 `1.0.1` 插件已修）。
- **撤销历史**：保存、切换主题、在「预览 / 源码」间切换，以及在标签间切换，都不再清空撤销/重做；每份打开的文档保留自己的编辑内容、撤销历史、光标和选区。**重启后不恢复撤销历史**（这是设计内的，不是缺陷）；「刷新（F5）」或明确重新读取磁盘内容会重置该文档的历史。
- **标签数量与内存**：每份打开的文档各有一个编辑区，实测 20 份约 4 KB 文档时内存增加约 2 MB，全部切到源码再多约 1.5 MB；关闭标签即释放。缩放与换主题只重排屏幕上的那个编辑区，回到其它标签时才补上样式，所以标签多时不会明显变卡。
- **换主题与阅读位置**：0.2.8 实测桌面**预览**状态下换主题，大致停在原来那一段（900 行长文实测顶部行号相差不超过 3 行）；任务书 E06 要求的“按行号精确恢复并与撤销行为分开验收”**还没做**，所以这条仍按“待核对”记，不宣称已经完全修好。阅读位置在**重启后**恢复、在同一标签内切换视图时也保留。
- 单篇文档渲染在 MB 级时约 1–2 秒（见 `docs/DEVELOPMENT.md` 的性能基线），超大文档会有可感知的等待。
- 升级会先备份程序文件，但**不会**备份你的工作区；重要资料请自己留存副本。
