# C02 导出预检定位（首版）

日期：2026-09-28。版本：0.4.5。范围：沿用既有 Word/PDF 导出流程，增加问题行定位和处理建议。

状态：0.4.5 定位首版和桌面测试版同步完成；0.4.6 补充实际 PDF 保存前预览，验证记录见文末。

预检中的缺图、越界图片、图片读取失败、远程图片、本地死链、过宽表格、不支持公式现在带有原文行号和片段。重复引用分别列出，代码块内的图片、链接和表格不作为正文问题。

桌面「导出前检查」窗口列出处理建议和可定位的行；选择一项后点「定位所选问题」，或双击该行，停止本次导出并选中对应源码行。窗口居中，配色跟随浅色、深色和护眼主题。阻止项仍不能继续导出，提示项仍可确认继续。

定位前核对文档身份和预检内容指纹。用户切换文档、修改正文，或选择磁盘版本但当前有不同的未保存内容时，拒绝使用旧行号，要求重新预检。定位不会替换正文、保存源文件或丢弃编辑内容。

## 0.4.6：实际 PDF 保存前预览

从工具栏菜单勾选「PDF 保存前预览页面」后，生成流程暂不提交目标文件。居中且随主题的窗口显示最终 PDF 本身，支持上一页/下一页、左右方向键、50%–200% 缩放、滚动和返回修改。默认关闭，不增加普通导出的确认步骤；Word 导出不触发 PDF 预览。

用户确认后复用同一个已生成产物，不重跑导出。提交前及最终读取字节时核对预览指纹，避免保存与已查看内容不同的文件。目标在等待期间改变时仍须重新确认；取消、渲染失败均不写目标，取消预览清理本次任务临时文件。

渲染在后台完成，窗口继续响应；最近三页/缩放结果缓存，上限 1800 × 2400 像素，关闭后释放。关闭正在渲染的预览时等待本次渲染结束后释放，避免在后台仍使用图片时关闭缓存。PDFium 调用统一串行，不同时在多个线程中调用，依据 [官方线程说明](https://pypdfium2.readthedocs.io/en/stable/python_api.html)。

桌面测试版运行环境新增本机已安装的 pypdfium2 5.12.1 及配套 PDFium，约增加 8 MB（包含 Python 模块与许可证，不含缓存）。完整 dist-info 许可证目录随运行环境复制；以后准备运行环境也复制所需模块。许可证依据 [项目说明](https://github.com/pypdfium2-team/pypdfium2#licensing)，不联网获取文档或渲染内容。
