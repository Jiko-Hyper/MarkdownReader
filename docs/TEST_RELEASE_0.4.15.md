# 本地测试版 0.4.15 收尾记录

历史记录：卸载清空目录的规则已被 0.4.16 替代。当前卸载必须保留项目及用户文件、清除 API 配置和程序数据，参见 `TEST_RELEASE_0.4.16.md`。

日期：2026-10-14。范围为当前源码测试版及对应本地安装包；未修改正式安装，未发布远端。

## 修复与操作

- 正文定位改为 `Ctrl+Shift+E`，不再吞掉大写 M。链接地址中的同名文字不参与正文定位；强调拆分的英文单词、重复段落、实体、Unicode、代码及嵌入对象附近文字均有双向回归。无选区时定位源码光标或预览当前阅读位置，`Ctrl+E` 保留各视图独立位置。
- 「打开文件夹」显示目录中的文件，可进入目标目录后点「打开当前文件夹」；可选择空目录，取消不改变原选择。侧栏单击目录行展开，双击不会再次折叠，Enter 可展开或收起。
- 新增 `卸载.exe`（57,856 字节），与卸载脚本和安装记录一起随包提供。确认显示的两个路径后，完整删除所选程序目录和配置数据目录的全部文件，包括额外文件、组件、文档、配置与密钥。原解压包入口按安装回执定位目标；临时执行脚本在程序目录之外运行，可删除卸载 EXE 本身。取消、目标不匹配、记录损坏、危险路径、链接及运行中安装均保留或拒绝。
- 精简主程序直接复用既有识别组件清单；本次不重复打包模型。增量包始终附带当前更新入口与更新器，避免旧更新器无法识别新增文件。
