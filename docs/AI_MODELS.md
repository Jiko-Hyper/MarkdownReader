# 在软件中使用 GPT、Claude、DeepSeek Flash

## 点击即可配置

1. 正常打开「MDReader 0.4.0 或更新版本」。如果更新时窗口已打开，先保存文档、关闭并重新打开。
2. 点击顶部 **AI 接入**，就在「浏览器视图」和「更多」之间。
3. 选择 **GPT（OpenAI）**、**Claude（Anthropic）** 或 **DeepSeek**。
4. 粘贴该服务商的 **API Key**。没有密钥时可以点「获取密钥」前往服务商网站申请。
5. 模型和官方地址已预填；点击 **保存并获取模型** 查看当前账户的模型，也可手动输入任意模型 ID。预填值只是默认值，软件没有模型版本白名单；实际可用性取决于账户权限、服务商是否仍提供该模型以及是否支持文本对话。
6. 点击 **测试连接**。成功后，在下方输入问题，点击 **发送** 或按 Ctrl+Enter。

无需 PowerShell、环境变量或手工启动后台服务。三家设置分别保存，可以随时切换。
API Key 是服务商提供的 API 凭据，不能填网页版登录密码。
测试连接会发送一条简短生成请求；测试和对话均按服务商 API 规则计费，软件不代购额度。

## 文档协作

- 可让 AI 解释代码、梳理需求、编写开发计划、生成或润色 Markdown。
- **附上当前文档** 默认关闭。只有勾选时，当前编辑内容（含未保存内容）才会随本次请求发送给所选服务商。
- 勾选后直接说“在最后一行添加你好”等修改要求。AI 会返回改动说明和待应用的正文，桌面端显示修改差异；点击 **应用修改** 才会替换编辑缓冲并更新桌面预览。普通问答不会要求替换文档。
- 应用前会检查原文和文档身份。等待期间切换文档或继续编辑时，不会覆盖新内容；请回到原文档或重新生成修改。格式错误或达到输出长度上限的结果不能应用。
- 桌面端在源码编辑器中按 Ctrl+Z 可一次撤销；浏览器端应用后显示源码，并可在助手窗口点击 **撤销此次修改**（继续编辑后不会覆盖新内容）。修改不会自动保存。
- 不会自动扫描项目或上传整个文件夹。
- **复制回复** 可粘贴到其他位置。
- **插入回复文本** 用于把普通回复插入光标处。修改文档请使用 **应用修改**，不应将整段解释重复插入正文。
- 对话按服务商分开，仅保留在当前窗口。**新对话** 清除当前服务商的历史，关闭窗口不保存聊天记录。
- 请求在后台执行，等待回复时仍可操作主窗口；关闭对话窗口不会保证撤销服务商已经收到的请求。
- 此版本为文本对话，不执行 AI 生成的终端命令或自动调用文件操作工具。

## 密钥与连接

密钥使用 Windows 当前账户的 DPAPI 加密后写入工作区 `ai-providers.json`，界面与本地设置查询接口
不会返回已保存密钥。输入框留空表示保留已有密钥，填写新值会替换；**清除已保存密钥** 用于删除。
加密文件不能直接搬到另一个 Windows 账户继续使用，需要重新输入密钥。

接口地址默认无需修改。如果使用兼容服务或代理，填写基础地址：OpenAI / Claude 通常包含 `/v1`，
粘贴完整的 `/responses`、`/messages` 或 `/chat/completions` 地址时，软件会自动识别路径和接口格式。
更换地址时必须重新输入密钥，避免把原服务商凭据误发给另一个地址。
接口格式默认自动选择：OpenAI 官方地址使用 Responses，Claude 使用 Messages，DeepSeek 和 OpenAI 兼容地址使用 Chat Completions。也可手动选择接口格式，以匹配模型或代理服务。OpenAI 官方 Responses 返回 404 或 405 时，自动模式会尝试同一模型的 Chat Completions 接口。
自定义服务必须支持所选协议。服务端拒绝跟随重定向，防止凭据被转发到其他目标。

发送后，对话区显示等待状态；失败时显示错误原因，并保留输入以便修改重试。

常见问题：

- **401 / 403**：核对密钥和账户权限。
- **404**：核对模型 ID、模型权限和基础地址；点击获取模型或向服务商确认。
- **429 / 402**：检查额度、余额或调用频率。
- **超时**：检查网络或稍后重试；不会自动重复收费请求。
- **长度限制**：单次请求的文档与对话合计不超过 20 万字符，最多 40 条消息，过长时请新建对话。

顶部「AI 接入」用于本页的模型调用。原来的外部软件控制入口移到了
**更多 → 外部 AI 控制接口（高级）**，两者的密钥互不通用。

## 实现依据与验证范围

- [OpenAI 文本生成 / Responses](https://developers.openai.com/api/docs/guides/text)：聚合所有输出消息中的 `output_text`，不假设第一条输出就是正文。
- [GPT-5.4 mini 模型说明](https://developers.openai.com/api/docs/models/gpt-5.4-mini)：作为 GPT 初始模型，可自行更改。
- [Claude Messages API](https://platform.claude.com/docs/en/api/messages/create)：单独传入 system、messages 和 max_tokens；只展示正文内容。
- [Claude API 使用说明](https://platform.claude.com/docs/en/claude_api_primer)：Claude 初始模型使用 Haiku 4.5，可获取并选择其他模型。
- [DeepSeek Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)：默认模型 `deepseek-flash`，其他模型可直接输入模型 ID，不统一附加思考模式参数。

自动测试使用本机模拟服务验证三种请求格式、鉴权、回复解析、错误处理、密钥存储和编辑器插入。
真实账户的模型可用性、余额和网络连通性需在填写密钥后通过界面的「测试连接」验证。
