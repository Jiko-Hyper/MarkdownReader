# C01 两套导出样式

日期：2026-09-28。负责人：本次开发任务。基线：当前源码 0.4.4。状态：源码与本地插件包验收完成，尚未发布新的桌面安装包。

场景：用户交付普通报告或技术说明，需要清晰的标题、表格和代码，仍可离线使用。

改动前：两个既有导出插件只有固定版式；Word 的标题层级外观区分较弱，长表尾页留白较多。

最小交付：在现有插件中提供简洁报告、技术文档两套样式；工具栏选择样式，所有桌面导出入口复用该选择；核心 API 使用 `options.style`。默认简洁报告，打印配色与阅读主题分离。技术文档使用蓝色标题、紧凑表格、代码底色。样式控制排版，不改变源 Markdown。

暂不包含：模板商城、可编辑 Word 公式、自动目录、复杂论文样式、转换插件改动。已有公式、脚注和 Mermaid 降级继续提示，不因换样式声明保真。

涉及：既有 export-pdf/export-docx 1.0.5、共用 exporting.py、export_ui.py、统一导出选项及固定样本工具。用户需显式更新旧插件才能使用技术文档样式；不自动修改真实用户工作区。

验收：两样式各运行全部 24 份固定样本；验证结构、内容、失败保护与分页；Word 重开结构、重复导出稳定性、阅读主题独立性及两种 PDF 阅读引擎复验。真实页面观察与未覆盖项另记，自动通过不代表视觉通过。

## 使用方式

工具栏「导出 Word/PDF」→ 选择样式 → 再次打开菜单选择格式。默认简洁报告，样式选择在本次程序运行期间保留；「更多」中的官方导出命令使用相同选择。旧插件选择技术文档时，先在居中且随当前主题的弹窗中「更新并启用」，随后重新发起导出。升级仍经过受信哈希校验，失败不显示成功状态。
