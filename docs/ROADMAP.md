## 2026-09-25 / 0.2.8：E01 切换视图与标签后仍可撤销

- **用户问题**：0.2.7 在保存和切换主题后还能撤销，但在「预览 / 源码」间切换、或切到另一份文档再回来时，撤销历史会清空；阅读自己的修改再返回后无法撤销刚才的编辑。
- **根因**：整个窗口只有**一个** `tk.Text`，同时承担两种视图和所有标签——切视图和切标签都要整块重写控件内容，而重写内容会清空 Tk 的撤销栈（`edit_reset`/整段 delete+insert）。
- **改动**：每份打开的文档持有**自己的源码编辑控件**，预览改为**独立的只读控件**；两者是同一网格单元里叠放的兄弟控件，切换视图与标签只做「显示哪一个」和「聚焦」，不再改内容。
  - `winui.py`：新增 `_new_editor` / `editor_for` / `_load_editor` / `_show` / `_sync_view`；`stash_tab` 改为记录屏幕上网控件的滚动位置与编辑控件的光标；`close_tab` 增加 `_release_editor`（销毁控件、注销输入法适配项、解绑事件）；`render()` 只画预览控件。
  - 保存基线与撤销栈分离：新增 `mark_baseline` / `at_baseline`（内容哈希），`on_modified` 用「是否回到基线」决定未保存标记，于是撤销回保存内容时标记自动消失、重做后恢复。
  - `ime.py`：把**每个可编辑控件各自的 16 毫秒轮询定时器**改成**窗口级钩子上的一个共享轮询循环**（标签再多也不会成倍增加原生桥调用）；`_show` 切走控件时清理其组合状态，避免在隐藏控件上残留拼音浮层；`InlineIME.close()` 用于标签关闭时从钩子注销。

## 本轮已实现

### 临时查看：拖进来就地读、就地改（本轮主题）

面向「手边有个 .md，想马上看、顺手改两句」的场景，**不产生副本**：

- 新增 `core.LooseDocs`：只记住文件的绝对路径，读写都直接作用在原文件上；
  最近打开记录存在工作区的 `recent.json`，条目失效时标记 ⚠ 而不是静默失败。
- 拖放：把 `.md` 拖进窗口、或拖到桌面图标 / `启动 MDReader.bat` 上，即为临时查看。
  原生窗口通过 `WM_DROPFILES`（`winui.FileDrop`）接收系统拖放；拖入**文件夹**或
  按 **Shift** 拖文件才是导入项目。
- 保存：`Ctrl+S` 或正文上方按钮写回原目录；新文档首次保存时选择位置；
  另有「另存为…」与「＋ 加入项目（复制/移动）」。
- 网页界面同步支持：侧栏「最近打开」、📂 打开本地文件、＋ 新建临时文档，
  以及 `/api/loose/*` 接口。浏览器标签页拿不到真实路径时明确降级提示，
  不会假装成功。
- 边界：非 Markdown 文件、目录、不存在的路径、超过 8 MB 的文件一律拒绝并说明原因；
  临时文档的相邻图片只允许从它自己的目录取（`/api/localfile`）。

### 其它修复

- `storage.atomic_write` 不再使用 `tempfile.mkstemp`：`mkstemp` 在创建失败时会
  无限重试，看似卡死；改为 `os.open(O_CREAT|O_EXCL)` + 有界重试，失败即报错。
- 多个 `Handler.api` 全局引用改为 `core.api_of(httpd)`，与「每个服务实例拥有
  自己的 API」保持一致（否则 `--serve` 直接崩溃）。
- `tests/__init__.py` 把测试临时目录固定到项目内 `.testtmp`，避免受限环境下
  `%TEMP%` 不可写导致测试假失败；`scripts/check.ps1` 同步用 `-t .` 发现测试。
- 新增 `tests/test_ui_wiring.py`：界面与接口的静态一致性回归（元素 id、接口路径、
  临时查看入口是否还在）。
- 每个测试包都用「临时查看」用例补齐服务端行为，测试数据全部落在项目内临时目录。
