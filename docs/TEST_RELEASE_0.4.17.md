# 本地测试版 0.4.17：侧栏输入搜索

仅更新桌面测试版与本地安装包，继续遵守 `AGENTS.md` 中的维护及卸载保留规则。

「我的文件夹」「项目」采用可编辑选择框。键入名称或路径后即时筛选，英文不区分大小写；结果显示在不抢走输入焦点的主题列表中，支持上下键、Enter 和鼠标选择。只有确认结果才切换目录或项目；清空输入显示全部记录，Esc 恢复当前选择。同名记录显示路径，未匹配时不可误选。刷新保持正在输入的查询，内部仍以完整历史列表的索引处理选择，避免筛选后切换或移除错误项目。

输入区、下拉结果与中文拼音组合使用现有「最近打开」搜索框的主题配色和输入法适配，覆盖明亮、夜间、护眼三种主题。普通 Delete 正常删字；历史移除改为 Ctrl+Delete，确认框和保留用户文件的行为不变。快捷键说明与使用手册同步更新。

验证：

- `tests.test_sidebar_search`：6 项通过，覆盖名称与路径筛选、同名目录、输入焦点、确认切换、无结果、Escape、清空、方向键、后台刷新、Delete 与历史保留、三种主题及中文组合背景。
- 完整 Python 回归：922 项执行，结果通过，2 项环境跳过，日志 `.testtmp/search017-full.log`。
- 隔离真实窗口确认点击文件夹框后直接输入中文、显示结果并按 Enter 切换；明亮与夜间主题已实际显示。用户随后通过 Escape 停止界面自动检查，因此未继续操作窗口；项目选择及三种主题由控件回归验证。

发布采用精简主程序包与 0.4.16 → 0.4.17 增量包，复用独立识别组件。保留新版卸载可执行文件，清除 API 配置并保留项目与用户自有文件的规则沿用 0.4.16。
