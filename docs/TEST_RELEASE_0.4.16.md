# 本地测试版 0.4.16：卸载重置 API 并保留用户文件

用户确认规则已写入仓库 `AGENTS.md`。本轮仅更新测试版和本地安装包。

卸载清理程序文件清单中的文件、本程序所有 API 服务商配置与加密密钥、外部 AI 控制接口配置、主题和阅读设置、历史记录、恢复与公式缓存、可识别的插件及识别组件。API 凭据只保存在所选配置目录的 `ai-providers.json`，使用 Windows DPAPI 加密；没有额外的系统凭据库条目需要删除。外部 AI 控制配置是同目录的 `ai-connection.json`。

保留 `projects`、项目元数据与附件、用户自行创建的项目目录，以及程序目录和配置目录内清单外的所有用户文件，不按扩展名判断。对无法确认归属的文件采取保留策略。卸载只逐个删除已确认的程序文件，再删除空目录，不递归清空两个目标目录。目录外的原文件不参与删除。

安装包携带 `program-files.json`，安装器保留程序所有权清单。组件和插件安装也记录自身文件清单，防止清理时连带删除用户后来放入的文件。旧版本没有清单时先用新版测试安装包升级。卸载后原路径仍有用户文件时允许重装；与程序文件同名的内容会停止安装，避免覆盖。

已通过实际安装包验证的完整流程是：在隔离目录安装 → 为所有服务商保存相同测试密钥 → 创建项目、附件及不同类型的用户文件 → 卸载 → 确认 API 和接口配置消失、用户文件逐字节保留 → 原路径重新安装 → 所有服务商 `has_key=False`，请求前必须重新填写 API Key → 显式再次输入相同测试密钥后才恢复已配置状态。该流程无需发送任何网络 API 请求。

测试日志使用 `.testtmp/uninstall016-*.log`，不会读取或删除真实用户配置。

验证结果：完整源码回归 916 项通过（2 项环境跳过）；卸载专项 60 项断言通过；实际安装包完成原路径卸载重装，3 个服务商均未配置 API、相同测试密钥必须显式重新输入，2 个项目及 12 个用户文件逐字节保留。0.4.15 → 0.4.16 增量更新入口也已验证。精简包 97,728,142 字节，增量包 845283 字节；模型组件未重复打包。
