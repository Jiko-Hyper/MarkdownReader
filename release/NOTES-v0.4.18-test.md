# MDReader 0.4.18 本地测试版

下载包和安装目录的外层简化为五项：

```text
MDReader.exe
安装.exe
卸载.exe
使用手册.md
resources/
```

双击主程序即可免安装使用，双击 `安装.exe` 可选择程序和配置目录并创建桌面入口。源码、运行时、内部脚本、安装记录和清单集中在资源目录。开发测试文件不再随主程序分发；资源文件夹须与可执行文件一起保留。

从旧版升级：先保存并关闭测试版，完整解压本版精简包，运行 `安装.exe` 并选择原来的两个目录。旧程序清单内的散落文件会整理，识别组件不重复打包，项目、额外用户文件和 API 配置在升级时保留。无法确认归属的文件原地保留，因此存在用户文件的旧目录可能仍然存在。

卸载继续运行 `卸载.exe`：清除本程序配置与全部 API 密钥，保留用户项目和所有自有文件。原路径重装后须重新配置 API。安装和卸载入口都有图标，正常使用不打开脚本控制台。

本次目录结构发生变化，使用完整精简安装包升级，不提供旧目录格式的增量包。仅更新桌面测试版和本地安装包，正式安装未修改。
