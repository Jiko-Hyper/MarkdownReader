# MDReader 0.4.17 本地测试版

「我的文件夹」与「项目」选择框支持直接打字搜索：

- 输入名称或路径的一部分即可筛选，英文不区分大小写，右侧箭头仍可展开列表。
- 按上下方向键选择结果，Enter 或点击结果后切换；输入过程不会切换当前项目或目录。清空文字显示全部记录，Esc 恢复当前选择。
- 同名记录显示路径区分，未匹配时显示“没有匹配项”。后台刷新不会抹掉正在输入的搜索文字。
- 参照「最近打开」搜索框，输入区、结果列表和中文拼音组合背景都跟随明亮、夜间或护眼主题。
- Delete 用于删字；移除历史记录改用 Ctrl+Delete，或选择框旁的 `×` 菜单，保留本地文件。

仅更新桌面测试版及对应本地安装包。继续采用 0.4.16 的卸载规则：删除本程序全部 API 配置和程序数据，保留项目与用户自有文件，重装后必须重新配置 API。识别组件独立复用，不重复打包模型。

完整安装使用本版精简程序包；现有 0.4.16 测试版也可使用 0.4.16 → 0.4.17 增量更新包。更新前保存文档并关闭测试版。
