# MDReader 0.4.16 本地测试版

卸载规则已更新，取代 0.4.15 的清空目录方式。

- 删除本程序的全部 API 服务商配置与加密密钥、外部 AI 接口配置、设置、历史、恢复缓存、插件和识别组件等程序数据。
- 保留用户 project、项目元数据、附件及全部用户自有文件，不限文件类型，也包括放在程序目录内的额外文件。无法确认属于程序的文件保留；含用户文件的目录继续存在。
- 卸载后重装必须重新配置 API。即使再次使用相同 API Key，也须由用户重新输入并保存，不能自动恢复“已有 API”。

保存并关闭测试版后，使用新版安装包升级原测试安装目录，再运行新版 `卸载.exe`。原路径重装会保留已有用户文件；存在与程序同名的文件时会停止，避免覆盖。

本轮只更新测试版和本地精简安装包；识别组件独立存放，不重复打包模型。

精简安装包约 97.7 MB，0.4.15 → 0.4.16 增量包约 0.85 MB。实际卸载重装已验证：3 个服务商均须重新配置 API，2 个项目和 12 个用户文件逐字节保留。
